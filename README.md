# java-lotto-precourse
# 로또 미션 기능 목록

# 🚀 3주차 로또 미션

로또 게임을 구현하며 객체지향 프로그래밍, 단위 테스트, 예외 처리를 학습합니다.

## ✅ 기능 목록

### 1. 로또 구입
- [ ] 로또 구입 금액 입력을 요청하는 안내 문구를 출력한다.
- [ ] 사용자로부터 구입 금액을 입력받는다.
- [ ] **[예외]** 입력값이 숫자가 아닌 경우 `IllegalArgumentException`을 발생시키고 `[ERROR]` 메시지를 출력한다.
- [ ] **[예외]** 구입 금액이 1,000원으로 나누어떨어지지 않는 경우 `IllegalArgumentException`을 발생시키고 `[ERROR]` 메시지를 출력한다.
- [ ] **[예외]** 구입 금액이 1,000원 미만(e.g., 0)인 경우 `IllegalArgumentException`을 발생시키고 `[ERROR]` 메시지를 출력한다.
- [ ] 예외 발생 시, 해당 부분(구입 금액 입력)부터 입력을 다시 받는다.

### 2. 로또 발행
- [ ] 구입 금액에 해당하는 만큼(금액 / 1,000원) 로또를 발행한다.
- [ ] "N개를 구매했습니다." 형식으로 구매 개수를 출력한다.
- [ ] 1~45 범위의 중복되지 않는 6개 숫자를 뽑아 `Lotto` 객체를 생성한다. (`Randoms.pickUniqueNumbersInRange` 활용)
- [ ] **[Lotto 클래스 검증]**
    - [ ] `Lotto` 번호가 6개가 아닌 경우 `IllegalArgumentException`을 발생시킨다. 
    - [ ] `Lotto` 번호에 1~45 범위를 벗어난 숫자가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
    - [ ] `Lotto` 번호에 중복된 숫자가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 발행된 모든 `Lotto` 객체 리스트를 화면에 출력한다.
- [ ] 로또 번호는 오름차순으로 정렬하여 `[1, 2, 3, 4, 5, 6]` 형식으로 출력한다.

### 3. 당첨 번호 입력
- [ ] 당첨 번호 입력을 요청하는 안내 문구를 출력한다.
- [ ] 사용자로부터 쉼표(,)로 구분된 6개의 당첨 번호를 입력받는다.
- [ ] **[예외]** 쉼표(,)를 기준으로 구분했을 때 6개가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] **[예외]** 각 번호가 1~45 범위의 숫자가 아닌 경우 (e.g., 문자, 범위 초과) `IllegalArgumentException`을 발생시킨다.
- [ ] **[예외]** 6개의 당첨 번호 중 중복된 숫자가 있는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 예외 발생 시, 해당 부분(당첨 번호 입력)부터 입력을 다시 받는다.

### 4. 보너스 번호 입력
- [ ] 보너스 번호 입력을 요청하는 안내 문구를 출력한다.
- [ ] 사용자로부터 1개의 보너스 번호를 입력받는다.
- [ ] **[예외]** 1~45 범위의 숫자가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] **[예외]** 이미 입력된 6개의 당첨 번호와 중복되는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 예외 발생 시, 해당 부분(보너스 번호 입력)부터 입력을 다시 받는다.

### 5. 당첨 내역 계산
- [ ] 사용자가 구매한 모든 로또를 순회하며 당첨 번호, 보너스 번호와 비교한다.
- [ ] 각 로또의 당첨 등수(1~5등, 꽝)를 판별한다. (Enum 활용 추천)
    - [ ] 1등: 6개 번호 일치 (상금: 2,000,000,000원)
    - [ ] 2등: 5개 번호 + 보너스 번호 일치 (상금: 30,000,000원)
    - [ ] 3등: 5개 번호 일치 (상금: 1,500,000원)
    - [ ] 4등: 4개 번호 일치 (상금: 50,000원)
    - [ ] 5등: 3개 번호 일치 (상금: 5,000원)
- [ ] 등수별 당첨 횟수를 집계한다.
- [ ] 총 당첨금을 계산한다.
- [ ] (총 당첨금 / 구입 금액) * 100 공식을 사용해 총 수익률을 계산한다.
- [ ] 수익률은 소수점 둘째 자리에서 반올림한다. (e.g., 62.5%)

### 6. 결과 출력
- [ ] "당첨 통계\n---"를 출력한다.
- [ ] 5등부터 1등 순서로 당첨 내역을 형식에 맞게 출력한다.
    - `3개 일치 (5,000원) - 1개`
    - `4개 일치 (50,000원) - 0개`
    - `5개 일치 (1,500,000원) - 0개`
    - `5개 일치, 보너스 볼 일치 (30,000,000원) - 0개`
    - `6개 일치 (2,000,000,000원) - 0개`
- [ ] 계산된 총 수익률을 형식에 맞게 출력한다.
    - `총 수익률은 62.5%입니다.`
